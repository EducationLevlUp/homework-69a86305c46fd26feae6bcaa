# Human-in-the-Loop через Middleware

Агент с `HumanInTheLoopMiddleware`, который останавливается перед каждым вызовом
инструмента, запрашивает подтверждение у пользователя и возобновляет выполнение
через `Command(resume=...)`.

## Структура проекта

```
hitl_agent.py          # основной скрипт
requirements.txt       # зависимости
README.md              # этот файл
```

## Зависимости

```bash
pip install -r requirements.txt
```

## Настройка

Требуется переменная окружения `OPENAI_API_KEY`:

```bash
export OPENAI_API_KEY='sk-...'
```

> **Важно:** никогда не вставляйте реальные ключи в код. Используйте `.env` или
> переменные окружения.

```bash
python hitl_agent.py
```

## Как это работает

1. **Инициализация** — агент создаётся с `HumanInTheLoopMiddleware` и
   `MemorySaver` как checkpointer. Middleware настроен на паузу перед вызовом
   `get_weather`.

2. **Первый вызов** — `agent.invoke({"messages": [...]}, config)` запускает
   выполнение. Если агент хочет вызвать инструмент, в результате появится ключ
   `'__interrupt__'`.

3. **Обработка прерывания** — из `result['__interrupt__'][0].value` извлекаются
   `action_requests` и `review_configs`. Для каждого действия выводится имя
   инструмента, аргументы и описание.

4. **Решение пользователя** — ввод `a` (approve), `r` (reject) или `e` (edit,
   если разрешён). Решения собираются в список в том же порядке, что и
   `action_requests`.

5. **Возобновление** — `agent.invoke(Command(resume={"decisions": decisions}), config)`
   продолжает выполнение в том же потоке.

6. **Цикл** — шаги 2–5 повторяются, пока в результате есть `'__interrupt__'`.

7. **Финальный ответ** — когда прерываний нет, ответ берётся из
   `result['messages'][-1].content`.

## Пример диалога

```
💬 Введите сообщение (или 'exit' для выхода):

Вы: Какая погода в Казани сегодня?

────────────────────────────────────────
🔧 Инструмент: get_weather
📦 Аргументы: {'city': 'Казань', 'date': 'сегодня'}
────────────────────────────────────────
a = approve, r = reject, e = edit: a

🤖 Агент: В Казани сегодня +20 °C, солнечно, без осадков.
```

При reject:

```
a = approve, r = reject, e = edit: r
Сообщение для агента (причина отказа): Не нужно, спасибо

🤖 Агент: Понял, не буду проверять погоду. Чем ещё могу помочь?
```

## Безопасность

- API-ключи передаются только через переменные окружения.
- В коде нет жёстко закодированных секретов.
- Инструмент `get_weather` — заглушка, не выполняет реальных сетевых запросов.
